# Fig2AE — Figma → After Effects

Перенос макета из Figma в AE. Каждый слой уезжает либо **точным вектором**
(геометрию считает сама Figma), либо **точными пикселями** + предупреждение.
Тихих приближений нет: всё, что не один-в-один, будет в списке после импорта.

Проверено в After Effects 26.2 рендером тестовой сцены — 82/82 проверок по пикселям
(`test/ae/`).

## Что нового в 0.4 — панель как в AEUX

**Установка (Windows):** скачай и запусти `Fig2AE-Setup.exe` → «Установить».

**Панель в After Effects** — Window → Extensions → **Fig2AE** (интерфейс и функции как у AEUX):
- **+ New Comp / ↓ Current** — экспорт из Figma создаёт новую композицию или кладёт слои в текущую
  (активную) композицию: фрейм центрируется, все слои начинаются там, где стоит курсор таймлайна,
  прекомпы получают частоту кадров и длину этой композиции, референс прошлого импорта заменяется новым.
  Если активной композиции нет — создаётся новая.
- **Options**
  - *Image save path* — куда сохраняются экспорты и картинки (папка-кнопка / ✕ — сброс на `Документы/Fig2AE`).
  - *Detect parametric shapes* — прямоугольники и эллипсы приходят как Rectangle/Ellipse AE
    (Size и Roundness анимируются), а не как bezier-пути. Только где контур точно такой же:
    один радиус скругления, без corner smoothing, полный эллипс.
  - *Precomp groups* — каждая группа/фрейм Figma становится прекомпом. Выключено — группа остаётся
    плоской; с галочкой *Group nulls* её слои привязаны (parent) к null-слою с именем группы.
- **Groups** (работают с активной композицией)
  - *Precomp* — выделенные слои в прекомп, обрезанный по их границам; всё остаётся на месте.
  - *Un-Precomp* — слои выделенного прекомпа возвращаются в эту композицию на те же места
    (родители и трек-матты внутри сохраняются).
  - *Toggle guide layer visibility* — показать/скрыть guide-слои (референсный кадр Figma), включая вложенные прекомпы.
  - *Delete group layers* — удалить null-слои групп (выделенные или все), дети остаются на местах.
- **System** — статус сервера, последний импорт и его предупреждения, импорт сохранённого `.jsx`, папка экспортов.

Настройки панели лежат в `%APPDATA%\Fig2AE\settings.json`; плагин Figma запрашивает их у AE перед экспортом.

**Плагин Figma** — новый интерфейс: тёмная тема в стиле Notion, иконки, статус соединения с AE
(и куда пойдёт импорт: новая / текущая композиция), FPS/длительность/масштаб — в разделе Advanced.

## Скачать, обновления, выпуск версии

- **Скачать:** https://github.com/fggtf24-cyber/fig2ae/raw/main/Fig2AE-Setup.exe (то же на сайте Яйца Клауд) —
  один файл, кнопка «Установить», без прав администратора. Без exe: `Fig2AE.zip` → `Install.cmd`.
- **Автообновление** (как у VoiceType): Fig2AE в After Effects через 5 секунд после запуска AE и потом каждые
  6 часов читает `version.txt` из ветки main. Если версия новее — скачивает `Fig2AE.zip` оттуда же, ставит поверх
  и сразу перезагружает себя (сервер и панель) — **без перезапуска AE и без Setup**. Плагин Figma обновляется
  на диске и подхватывается при следующем открытии плагина. Перезапуск AE нужен, только если изменился
  `cep/CSXS/manifest.xml` (новая панель и т.п.) — тогда панель так и пишет. Выключается галочкой
  «Update automatically» в панели → System; там же «Check for updates».
- **Выпустить версию:** `node make-release.js bump 0.4.2` → `npm test` → commit (вместе с `Fig2AE-Setup.exe`, `Fig2AE.zip` и `version.txt`) → push в main.
- Плагин Figma ставится в `%LOCALAPPDATA%\Fig2AE\figma-plugin` — импортировать в Figma оттуда, тогда его обновляет автообновление.

## Почему AEUX переносит криво (найдено в его исходниках)

AEUX заархивирован в июне 2025 и больше не чинится. Конкретные причины:

| Баг AEUX | Что здесь |
|---|---|
| Радиальный градиент берёт только `radius[0]` — эллипс становится кругом. А в Figma радиальный градиент на неквадратной фигуре по умолчанию эллипс | Эллипс через трансформ группы: в группе градиент круглый, группа его сплющивает и поворачивает, пути получают обратную матрицу |
| Линейный градиент берётся по ручкам Figma — на неквадратной фигуре другой угол | Изолинии считаются в пикселях из `gradientTransform`, конец градиента = `S + ∇g/|∇g|²` |
| Прозрачность градиентной заливки всегда 100% | Переносится |
| Угол тени через `atan(y/x)` — при отрицательном X тень уходит в другую сторону | `atan2`; для картинок и прекомпов — в системе слоя (поворот/отражение сняты), для shape/текста — в системе композиции (так их считает AE) |
| Блюр 1:1, а у Figma и AE разные единицы | Откалибровано в AE: Figma R → σ = 0.568·R (bjango), Gaussian Blur = 3.55·σ, Softness тени = (σ − 0.5)/0.1917, Box Blur r = (σ − 0.494)/1.032 |
| Цвета градиента — из шаблонов `.ffx` фиксированной длины: максимум 8 стопов, значение вне 0..1 портит файл | `.ffx` генерируется заново с пересчётом всех чанков: любое число стопов и любые значения |

Overlord (Battle Axe) делает градиенты и текст хорошо, но его собственный changelog за 2025–2026 —
это список тех же граблей: радиальные на неквадратных фигурах, отступы box-текста, вертикальное
выравнивание, сглаживание углов, маски картинок. Здесь они закрыты так:

- **Геометрия** — из `fillGeometry` / `strokeGeometry` Figma: скругления (в т.ч. iOS-сглаживание), звёзды,
  булевы операции, inside/outside-обводки, пунктир, стрелки, переменная толщина — всё уже посчитано Figma.
- **Стык контура** — дублирующая вершина на `Z` сворачивается в первую (иначе в AE лишняя точка/излом).
- **Дырки** — winding rule (nonzero/evenodd) → Fill Rule.
- **Текст** ставится не по метрикам шрифта, а по **границам глифов**: в Figma — по контурам глифов
  (`fillGeometry` текста, точные экстремумы безье), в AE — по `sourceRectAtTime`. Отступы box-текста,
  правила базовой линии и разница метрик шрифтов взаимно сокращаются.
  - Посимвольные стили (шрифт, кегль, цвет, трекинг, интерлиньяж) — через `characterRange` (AE 24.3+).
  - Шрифт ищется через `app.fonts.getFontsByFamilyNameAndStyleName` (AE 24.0+).
  - Если шрифта нет — подставляется стандартный (Arial → Segoe UI → Helvetica → Tahoma) с сохранением
    жирности/курсива, текст остаётся редактируемым, выравнивается по краю абзаца. В отчёте — одна строка на шрифт.
  - Иконочные шрифты (Material Icons/Symbols, Font Awesome, Phosphor, Lucide…) рисуют значки из лигатур:
    если такого шрифта нет, иконка переносится контуром из Figma, а не словом «star» шрифтом Arial.
  - Трекинг в AE только целый (1/1000 em) — округляется, погрешность меньше 0.0005 em.
  - AUTO-интерлиньяж Figma измеряется, а не подставляются 120%.
  - Отступы box-текста убираются (`boxInsetSpacing = 0`, AE 24.6+), переполненный бокс растягивается.
- **Градиент в тексте** → настоящий градиент AE под живым текстом-маттом: текст редактируется,
  градиент правится как обычный. С тенью/блюром пара собирается в прекомп, эффект висит на нём.
- **Маски Figma** → трек-матты AE (alpha / luma / vector).
- **Background blur** → adjustment-слой с Gaussian Blur под маской формы.
- **Режим наложения у отдельной заливки** → Blend Mode у Fill в shape-слое.
- **Display P3** документы конвертируются в sRGB.
- **Цветовое управление проекта AE**: рабочее пространство «Rec.709 Gamma 2.4» (и другие 709/гамма) —
  все цвета пересчитываются точно (основные цвета те же, что у sRGB, отличается кривая). Для прочих
  пространств — предупреждение.
- **Композиции меньше 4 px** (AE не создаёт) — увеличиваются до 4, содержимое остаётся на месте.

## Всё, кроме картинок, — редактируемое

- **Картинки** переносятся **оригиналом целиком** (без обрезки) отдельным слоем, а форма узла
  (скругление, круг, вектор, маска) — отдельным векторным слоем-маттом. Картинку можно двигать и
  масштабировать внутри формы. Учитываются FILL / FIT / CROP, поворот, прозрачность и режим наложения
  заливки; TILE — через Motion Tile. Фильтры Figma (экспозиция, контраст…) запекаются в саму картинку.
- **Блюр на картинке** — Fast Box Blur (3 итерации) на прекомпе «картинка + форма», картинка внутри не размыта.
- **Inner shadow** — векторная конструкция: прямоугольник с дыркой формы узла, смещение = позиция
  подгруппы, spread = Offset Paths, плюс Gaussian Blur и матт по форме. Всё правится.
- **Градиенты — эффектами AE** прямо на фигуре или живом тексте, точки привязаны к слою (`toComp`):
  | В Figma | В AE | Точность (замер в AE 26.2) |
  |---|---|---|
  | 2 цвета, линейный / круглый радиальный | Gradient Ramp | точно |
  | затухание в прозрачность (из 0) | цвет / Gradient Ramp + Linear Wipe | ≤ 0.025 от Figma в середине, мягче у концов |
  | 3–4 цвета, линейный | 4-Color Gradient (Blend = 0.094·длина) | в точках почти точно, между ними до 0.12 |
  | 5+ цветов, эллипс, прозрачность не из 0 | градиент shape-слоя | точно, тоже правится |

  На 4-Color Gradient `setValue` для точек и Blend роняет скрипты AE 26.2 — они заданы выражениями.
- **Конический градиент** — веер из 180 векторных секторов под маттом.
  **Ромбовидный** — 4 линейных градиента AE (в каждой четверти ромб линеен — это точно).
- **Текст с градиентом/картинкой/обводкой inside** — живые копии текста служат маттами для настоящих
  слоёв заливки; обычный цветной текст остаётся одним слоем.
- **Маска из нескольких слоёв** — матт-прекомп, а не растр.
- **Фрейм с Clip content и скруглением** — дети обрезаются маттом по форме фрейма (карточка с картинкой
  на всю ширину остаётся скруглённой). Прекомп фрейма расширен на его внешнюю обводку и тени — они не
  обрезаются. Обводка фрейма лежит над детьми, как в Figma.
- **Наклон (shear)** — бывает у повёрнутых слоёв внутри растянутой группы. Слой получает поворот и
  масштаб, наклон — эффект Transform (Skew) вокруг anchor point.
- **Spread у тени** — тень становится отдельным векторным слоем: контур узла + Offset Paths + смещение
  группы + Gaussian Blur. Всё правится.
- **Подчёркивание / зачёркивание** — плагин снимает декорацию на клоне узла и забирает из Figma ровно те
  контуры, которые исчезли. Они ложатся отдельным векторным слоем поверх живого текста, цвет — как у символов.
- **Обрезка многоточием** — плагин на клоне находит, какие символы Figma реально показывает (самый длинный
  префикс + «…», который влезает в бокс), и сверяет контуры с оригиналом. В AE уходит живой текст
  с этими символами.
- **Тени у повёрнутых / отражённых слоёв** — замерено в AE 26.2: shape- и text-слои применяют эффекты
  в пространстве композиции (после своего трансформа), картинки и прекомпы — в пространстве слоя.
  Направление тени, блюр и наклон пересчитываются для каждого случая отдельно.
- **Ошибка в одном узле не ломает экспорт** — такой узел переносится пикселями Figma, в отчёте строка с причиной.

В PNG уходит только то, что и так пиксели: видео- и паттерн-заливки, неизвестные типы узлов.
Noise, Texture и прогрессивный блюр — точными пикселями Figma (в AE нет аналога), с предупреждением.
Glass пропускается с предупреждением.

Не переносится: маркеры списков, Glass. Подчёркивание и многоточие требуют редактируемого файла
(клон узла); в read-only файле — предупреждение. Background blur размывает только слои внутри той же композиции.

## Установка

**Windows — `Fig2AE-Setup.exe`**: обычный установщик, кнопка «Установить», без прав администратора.
В конце показывает путь к `manifest.json` (кнопка «Скопировать путь») для Figma: Plugins → Development →
Import plugin from manifest…. Удаление — Параметры Windows → Приложения → Fig2AE.
Exe не подписан: Windows SmartScreen может спросить — «Подробнее» → «Выполнить в любом случае».

**macOS:** `node install.js` из `Fig2AE.zip`.

Сборка: `node make-release.js` (exe компилируется `csc.exe`, который есть в любой Windows, или mono `mcs`;
`installer/Setup.cs`, `Fig2AE.zip` встроен ресурсом). `FIG2AE_TEST_ROOT=<папка>` уводит все пути и ключи реестра
установщика в песочницу — так он проверялся (`/quiet`, `/uninstall`).

Установщик ставит:
- **Fig2AE для After Effects** (`cep/`) в папку CEP-расширений пользователя: невидимый сервер, стартует вместе с AE
  (как сервер AEUX) и принимает экспорт из Figma на `localhost:7251`, и панель Window → Extensions → Fig2AE;
- плагин Figma в `%LOCALAPPDATA%\\Fig2AE\\figma-plugin` и `%APPDATA%\\Fig2AE\\install.json` для автообновления;
- `PlayerDebugMode = 1` для CSXS 9–16 (неподписанные расширения; только там, где ещё не стоит);
- панель ручного импорта `Scripts/ScriptUI Panels/Fig2AE.jsx` в каждую версию AE и удаляет старый
  «сторож» `Scripts/Startup/Fig2AE Startup.jsx` прошлых версий.

Перезапусти AE и включи: Edit → Preferences → Scripting & Expressions → «Allow Scripts to Write Files and Access Network».

## Работа — как в AEUX

Окно плагина в Figma:
- **«Отправить выделение в After Effects»** — выделение сразу строится в открытом проекте AE, без файлов
  и кликов в AE. Отчёт «что не один-в-один» показывается в окне плагина. Если в AE открыт диалог
  (Preferences, Composition Settings…), импорт ждёт, пока его закроешь, — без ошибок.
- **Референсный кадр** (галочка) — PNG фрейма, отрисованный самой Figma, ложится верхним слоем: guide-слой
  (не попадает в рендер), выключен и заблокирован. Включи «глаз» — и сравнивай с перенесённым.
- **Растрировать выделенные слои при экспорте** — пометка хранится на слоях в файле Figma. Помеченные
  слои (или целый фрейм) уходят в AE картинкой — пикселями Figma, с эффектами. Повторное нажатие снимает пометку.

Если AE не отвечает (закрыт, сервер не установлен), плагин сохраняет `fig2ae_<имя>.jsx` в «Загрузки»:
в AE — File → Scripts → Run Script File… или панель **Window → Fig2AE.jsx** («Импортировать последний экспорт»).

Экспорты, пришедшие через сервер, лежат в `Документы/Fig2AE/<дата_время>/` — там и картинки, на которые
ссылаются слои AE. Не удаляй папку, пока проект ими пользуется.

Почему не таймер в ExtendScript, как раньше: `app.scheduleTask` выдаёт «Cannot run a script while a modal
dialog is waiting for response», как только в AE открыт любой диалог. Сервер принимает только данные (JSON)
и собирает `.jsx` своим установленным импортёром — присланный код не выполняется (на localhost может
постучаться любая страница из браузера).

## Тесты

```bash
npm test
```

- `test/geom.test.js` — пути, дуги, границы безье, SVD, валидность `.ffx` для 2–17 стопов.
- `test/server.test.js` — сервер в AE: экспорт в свою папку, ожидание закрытия диалога, отказ на присланный код.
- `test/figma.test.js` — фейковая сцена Figma → `code.js` → `test/out/scene.jsx` (ровно то, что скачивает плагин).
- `test/ae/run.jsx` — запускает `scene.jsx` в настоящем AE и рендерит кадр;
  `node test/ae/check.js` проверяет пиксели (градиенты всех типов, multiply, поворот, маски, тени, inner shadow, картинки с маской и блюром, текст, градиентный текст, подмену шрифта).
- `test/ae/calibrate.jsx` + `node test/ae/check.js calibrate` — замер единиц блюра AE.

Тест-скрипты AE работают только в пустом несохранённом проекте и удаляют за собой всё, что создали.

## Заметки для разработки

- Картинки лежат **не в коде**, а в комментарии в конце `.jsx` (по одной base64 на строку): ExtendScript
  разбирает мегабайтные строковые литералы минутами, а комментарий пропускает. Импортёр читает их из своего
  файла и распаковывает системным `certutil` (Windows) / `base64` (macOS). Файл с двумя скриншотами 8 МБ:
  было >10 минут, стало 4 секунды.
- `.jsx` сохраняются в **UTF-8 с BOM** — без BOM ExtendScript читает файл как ANSI и кириллица ломает скрипт.
- `AfterFX.exe -r` не работает с путями с пробелами — запускай через короткий путь-обёртку
  или через File → Scripts.
- `comp.saveFrameToPng` рендерит эффекты; если блюр выглядит резким — проверь «Repeat Edge Pixels».
